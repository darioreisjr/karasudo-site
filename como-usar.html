Guia Completo: Do Download ao Uso Diário

Aprenda passo a passo como baixar, instalar e rodar o Karasudo no seu computador, conectar seus agentes de IA e dominar os atalhos do escritório.

Passo a Passo: Como Rodar no Seu Computador

Tudo roda localmente na sua máquina. Siga estas etapas para subir o escritório em minutos.

1

Baixe o Arquivo do Karasudo

Baixe o arquivo oficial pré-compilado (karasudo-0.1.8.tgz ou em formato .zip) em qualquer pasta do seu computador (por exemplo, na pasta Downloads):

Baixar karasudo-0.1.8.tgz (2 MB) Baixar em .ZIP (2 MB) Central de Downloads
Requisito único: Ter o Node.js instalado (versão 22.12 ou mais nova). Se ainda não tiver, baixe em nodejs.org. Não precisa de Git nem de ferramentas de compilação.
2

Abra o Terminal e Instale

Abra o Terminal (Prompt de Comando, PowerShell no Windows, ou Terminal no Mac/Linux) na pasta onde salvou o arquivo (ex.: na pasta Downloads) e digite:

npm install -g ./karasudo-0.1.8.tgz
Caso tenha baixado em .zip, descompacte o arquivo (você encontrará o karasudo-0.1.8.tgz dentro) e rode o comando acima na pasta.
3

Pronto! Inicie com um Comando

Agora o Karasudo está instalado globalmente. Você pode iniciá-lo a qualquer momento, de qualquer pasta do computador:

karasudo
O servidor iniciará instantaneamente no terminal mostrando: 🏢 Karasudo em http://127.0.0.1:1818.
4

Abra no Navegador

Abra seu navegador favorito e acesse:

http://localhost:1818 Porta do escritório
Privacidade total: Roda 100% local no seu computador, nada é enviado para a nuvem ou servidores externos. O Karasudo detecta sozinho as ferramentas que você estiver usando (Claude Code, Codex, Gemini e Antigravity) e mostra as salas e sessões em tempo real!
★

No Dia a Dia: Como Fechar e Reabrir

• Para fechar: Vá até o terminal e pressione Ctrl + C.
• Para abrir de novo: Você não precisa baixar nem reinstalar nada! Basta abrir qualquer terminal e digitar diretamente:

karasudo

Conectando Suas Ferramentas de IA

Execute estes comandos dentro da pasta do Karasudo para habilitar a transmissão de eventos ao vivo.

CLAUDE CODE

Claude Code

Instala o mod oficial do Karasudo para atualização em tempo real e resposta pelo escritório. Requer Claude Code 2.1.287+.

Comandos:
npm run mod:install
CODEX

Codex

Instala os hooks de eventos. Depois de instalar, abra o Codex, digite /hooks e aprove os hooks do Karasudo.

Comandos:
npm run codex:install
GEMINI CLI

Gemini CLI

Ativa a integração com as sessões do Gemini CLI. É necessário estar logado com sua conta Google no terminal.

Comandos:
npm run gemini:install
ANTIGRAVITY

Antigravity

O Karasudo monitora automaticamente o diretório ~/.gemini/antigravity e cria as salas dos projetos sem nenhuma configuração manual.

Instalação:
Detecção automática instantânea

Atalhos e Dicas de Uso Diário

Aproveite ao máximo a experiência enquanto você programa.

Comunicação P

Responder pelo escritório

Quando um agente levantar a mão precisando de aprovação ou fizer uma pergunta, pressione a tecla P para responder diretamente sem trocar para a janela do terminal.

Disponível no Claude Code e Codex.
Terminal T

Terminal ao vivo e cópia

Pressione T para abrir o terminal da sessão selecionada. Veja comandos em tempo real e exporte toda a conversa formatada em Markdown com um clique.

Exportação limpa e pronta para colar em pull requests.
Produtividade M

Painel "Meu Dia"

Pressione M para conferir o tempo gasto por projeto, tempo de espera humana, sessões abertas e custos com tokens no dia.

Perfeito para manter o controle diário das tarefas.
Multitarefa PiP

Modo Picture-in-Picture

Clique no ícone PiP na barra de ferramentas superior para manter um mini-escritório flutuante sempre por cima do seu VS Code ou terminal em tela cheia.

Você nunca mais perde um pedido de aprovação.

Significado dos Personagens no Escritório

Basta olhar para a tela para entender o que está acontecendo sem precisar ler logs.

Digitando na mesa: O agente está raciocinando ou editando código.
Mão levantada: Precisa de uma aprovação ou resposta sua.
De olho no terminal: Esperando a saída de um comando em segundo plano.
No café / descansando: Terminou a tarefa e aguarda novas ordens.
