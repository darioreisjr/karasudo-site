Passo a passo para rodar (Instalação Global Simples)

1

Baixe o arquivo: Salve o arquivo (karasudo-0.1.8.tgz ou karasudo-0.1.8.zip) em qualquer pasta (ex.: na pasta Downloads).

2

Abra o Terminal e instale: Na pasta onde baixou, execute: npm install -g ./karasudo-0.1.8.tgz

3

Inicie e acesse: Digite o comando abaixo e abra http://localhost:1818: karasudo Roda 100% local no seu computador, nada é enviado para servidores externos.

Requisitos Mínimos do Sistema

  • Node.js: Versão 22.12 ou mais recente (verifique com node --version).
  • Sistema Operacional: Windows 10/11, macOS ou Linux.
  • Navegador Moderno: Chrome, Edge, Firefox, Brave ou Safari (suporte a CSS Grid e PWA).
