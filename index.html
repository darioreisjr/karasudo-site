Conecte seus Agentes Favoritos

O Karasudo reúne as principais ferramentas de desenvolvimento por IA em um só lugar.

CLAUDE CODE

Claude Code

Suporte em tempo real com o mod oficial. Mostra atividades, permissões pendentes e permite responder direto pelo escritório.

Comando:
npm run mod:install
CODEX

Codex (CLI e Desktop)

Integração nativa via hooks. Acompanhe a execução das tarefas e interaja via terminal ao vivo.

Comando:
npm run codex:install
GEMINI CLI

Gemini CLI

Conexão transparente com as sessões do Google Gemini CLI no seu terminal local.

Comando:
npm run gemini:install
ANTIGRAVITY

Antigravity

Sem necessidade de instalar nada. O Karasudo detecta e lê automaticamente as sessões e projetos abertos.

Instalação:
Detecção automática instantânea
